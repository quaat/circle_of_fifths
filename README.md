# Circle of Fifths Interactive

A React/Vite learning app for exploring major keys and relative minor keys, progressions, contextual harmonic recommendations, and guitar chord charts. Select a circle segment, drag the dial, use the previous/next buttons, or focus a segment and use arrow keys. One major/minor choice applies across all details views.

Spelling is derived from the selected key. Auto chooses conventional spellings; forced sharp/flat alternatives can produce theoretical keys with double accidentals. The minor chart uses natural minor, while raised-leading-tone cadences are identified separately. See [harmony conventions](docs/harmony.md).

## Development

Use Node.js 22 LTS or a compatible newer version and npm. No API credentials or backend services are required.

```sh
npm ci
npm run dev
```

Vite listens on port 3000. Dependencies and compiled styles are local; the app needs no runtime CDN or font requests. Installation uses registry.npmjs.org. System fonts provide fallbacks for Inter and JetBrains Mono.

## Validation

```sh
npm run typecheck
npm test
npm run build
# Or run all three:
npm run check
```

Pull requests run the same quality checks in GitHub Actions. For Chromium browser tests:

```sh
npx playwright install --with-deps chromium
npm run test:e2e
```

A machine with compatible system Chromium can instead set `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` to its executable. Browser tests start their own Vite development and production-preview servers on ports 3100 and 3102. They cover key/mode navigation and local styles with external traffic blocked, including the GitHub Pages subpath.

## Build and preview

```sh
npm run build
npm run preview
# Explicit GitHub Pages asset path:
npm run build -- --base=/circle_of_fifths/
```

The Pages workflow derives its repository base from `GITHUB_REPOSITORY`. Tests can also override Vite's base using `--base`. A production preview is for local validation; publishing is handled separately by GitHub Pages.

## Current limits

Harmonic suggestions need musical context: they do not analyze an existing melody or guarantee interchangeability. Guitar fingerings generated by the current algorithm still need validation and guitarist review. Responsive layout, mobile touch and screen-reader review, and audio lessons are tracked as follow-up work.
